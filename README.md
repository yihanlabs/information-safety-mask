# 隐去 · 本地图片脱敏

中文本地浏览器工作台：批量导入图片，自动遮盖敏感文字，逐张调整并确认，下载清理元数据后的独立 PNG。图片由用户手动上传，应用不接入云端模型。

## 启动

本机环境与模型准备完成后，双击 **启动工具.cmd**（或 start.cmd）。浏览器会自动打开带本次访问令牌的本地页面。首次识别需要加载模型，长截图仍可能需要数分钟。首次启动使用低占用模式，以后记住用户在右上角“设置”中的选择。

识别进度显示在画布底部的一行中，点击箭头展开五个步骤。图片准备显示真实完成块数，文字识别显示真实完成行数；准备模型和寻找文字无法获得内部百分比，显示活动进度条及本阶段粗估时间。切换性能模式后重新估计，超过估计范围或失去连接时明确提示。

右上角“设置”可开启或关闭高占用模式：

| 模式 | 后台总 CPU 预算 | OCR 计算线程 | OCR 节能调度 |
| --- | --- | --- | --- |
| 低占用 | 20% | 2 | 开启 |
| 高占用 | 80% | 逻辑核数减 2，至少 2、最多 8，且不超过可用核数 | 关闭 |

两种模式均低于正常进程优先级、单张串行识别，沿用相同模型和检测比例；相同内存处理方式下识别批量也相同。解码、预览、OCR 和 PNG 生成共享一个总预算，由服务统一管理；图像处理进程仍保持 2 线程与节能调度，HTTP 服务保持独立。预算失败时保留低占用；进程无法加入预算时退为单线程并提示。设置中的“运行详情”显示实际状态。高占用可能增加温升和风扇声，实际速度提升尚待真实模型对照测速。

处理中切换会显示“本张完成后生效”；当前图片完成、失败或取消后，在下一张开始前应用。只重启 OCR 工作进程，首次识别需重新加载模型，图片、人工调整和确认状态不会因此清空。已完成的图片不重新识别。

CPU 加速使用锁定的 PaddlePaddle 3.2.2、PaddleOCR 3.3.2、PaddleX 3.3.13，保留 PP-OCRv5 server 原模型及精度。设置中显示加速状态；遇到已知的加速兼容异常时，在新进程中改用兼容模式重试一次，继续遵守当前资源限制，并在当前会话保持兼容模式。服务退出时同时结束后台识别进程。

长图已获得整图 CPU 加速收益。分块检测也已实现并验证：沿用原检测比例，每块 1536 像素、至少重叠 256 像素，字符仍从原图裁取，遇到无法消除的边界疑点会复查整图。本机密集长图测试中该方式触发额外复检，时间和内存均未达到启用门槛，因此当前默认关闭；日常使用采用已验证的整图加速。详见 VALIDATION.md。

更新程序后，请先下载当前批次需要保留的图片，再关闭旧启动窗口并重新启动。新版本使用独立的 **.venv-cpu** 环境，原 **.venv** 未被替换，当前运行中的旧会话可以继续完成导出。仅刷新页面不会切换后台运行版本。

首次安装或重建环境：双击 **安装与准备.cmd**（或 setup.cmd）。需要 Windows 10/11 x64、uv、Node.js 22 及以上，以及 pnpm 11 或 npm。脚本会下载 Python 3.11、锁定依赖及官方模型；首次准备需要联网。后续启动直接使用本地环境，无需联网、CUDA 或显卡。

关闭启动窗口或按 Ctrl+C 结束服务并释放当前批次。仅关闭浏览器标签页不会结束后台服务；可使用“清空当前批次”立即移除图片。

## 使用

### 内存偏紧时

应用会分别检查模型加载、解码和识别所需的新增内存，取消原先本机约 9.2 GiB 的固定加载门槛。物理内存和系统剩余可提交内存分开检查；对已知阶段的预计新增需求增加 25% 余量，并保留 1 GiB 系统空间。检测器工作区随图像形状和计算后端变化，未校准的总量不作为拒绝依据，后台持续监测实际余量。

可用物理内存或提交余量低于 8 GiB 时，下一张自动采用省内存方式：优先使用加密图片缓存、推理缓存容量从 10 降为 1、文字识别从最多 6 条改为逐条、实体分析从最多 16 条改为逐条；实体模型延后到有文字需要分析时加载。识别模型、检测比例、原图分辨率及 CPU 档位不变。8 GiB 是省内存方式的切换参考值，不是拒绝图片的门槛，也不代表任意图片的最低运行内存。

进度行显示“省内存”，展开步骤或设置中的运行详情可查看说明。内存恢复到至少 10 GiB 且提交余量足够时，自动选择的省内存方式可在下一张恢复常规处理；本会话若确实发生过内存失败，继续采用省内存方式以避免反复失败。

预检查不足与实际内存分配失败分别提示。常规方式遇到内存失败，会释放失败进程，最多自动以省内存方式重试一次；仍不足则显示“等待释放内存”，后续队列暂停，图片和手动补框保留。提示显示当前可用量、已知阶段预计需求及建议释放量；未知原生分配失败不会编造准确需求。释放内存后点击“重试处理”，会先重新检查；也可以移除该图，或在预览可用时完成人工检查并确认，让队列继续。

如果开着多个旧会话，请先下载需要保留的图片，再关闭不再使用的启动窗口。仅关闭网页标签不会结束后台模型。工具不会替你关闭其他会话或修改 Windows 分页设置。磁盘缓存不足和损坏图片会单独说明，不会误报成内存不足。

### 图片检查与下载

1. 拖入多张图片，或选择图片/文件夹。支持 PNG、JPEG、静态 WebP、BMP，每批最多 100 张。已取消 25 MB 和 3000 万像素的导入限制；大图保留原始分辨率，在后台分段准备。
2. 在右侧“批次规则”勾选人名、证件号码、详细住址、电话号码。设置应用于整个批次，未选类别不触发对应遮盖。
3. 在“自定义敏感内容”中输入实际文本，每行一项。各项可独立启用、编辑或删除。统一全角/半角并忽略空白，保留标点与大小写差异，不做模糊匹配。
4. 长图（高宽比至少 3:1）默认按宽度展开，从顶部开始；普通图适应窗口。工具栏可切换“适应宽度”和“查看全图”。按住“对照”查看原图，使用“补框”新增遮盖，选中已有框后拖动、缩放或删除。右侧“当前遮盖”可点击定位，选中后显示原因。人脸、签名、二维码等需手动框选。
5. 点击“确认此图片”或“确认并下一张”。修改遮盖后，本张确认失效；修改有效的类别或自定义匹配规则后，整个批次需要重新确认，即使没有新命中。
6. 点击“下载已确认图片”，或“导出本张”。批量时逐张生成 PNG，不再打包。下载详情显示生成进度和每张结果；失败项可重试，修改后确认失效的图片必须重新检查。若浏览器提示，请允许此本地地址下载多个文件；也可使用逐张下载入口。“已提交浏览器”表示已发起下载，请在浏览器下载列表检查文件是否保存。

下载详情位于顶部浮层，不挤压画布。成功后自动收起，可点击下载详情图标重新查看；失败项保持可见并可单张重试。

普通滚轮上下浏览，Ctrl＋滚轮围绕指针缩放，Shift＋滚轮横向浏览；平移模式可拖动画布，右侧滚动条可快速定位。每张图片在当前页面内记住缩放和浏览位置，切换图片或折叠侧栏不会跳回顶部。

快捷键：V 选择、R 补框、H 平移、Delete 删除选中框、Ctrl+Z 撤销、Ctrl+Shift+Z 重做；Home/End 到顶部/底部，PageUp/PageDown 翻页，F 专注检查，Esc 退出专注。侧栏可独立折叠，保留未提交的字段草稿。

“恢复自动遮盖”恢复当前图片中被取消或调整的自动框，保留手动新增的框。

## 识别与保存方式

- PaddleOCR 3.3.2 + PP-OCRv5 server 中文检测/识别，结合 spaCy zh_core_web_trf 3.8.0、本地格式规则与标签位置。
- 自动证件类别针对居民身份证及中国护照；其他号码可使用自定义内容。地址规则避免只因省市名称出现就遮盖。
- 优先使用文字片段坐标；片段无法可靠定位时遮盖整行，并显示提示。整行命中使用完整文本框，额外扩边减少残留笔画。
- 类别和字段用 Windows DPAPI 加密保存在当前用户的 %LOCALAPPDATA%/InformationSafetyMask/settings.json。字段需由同一 Windows 用户读取。右侧可清空自定义字段。
- 性能选择独立保存在同目录的 performance.json，只含模式名称，不含图片或敏感文本；清空敏感字段和重置规则不会改变性能选择。
- 普通图片优先保留在内存，图像内存缓存预算为 512 MiB；大图和较大上传数据使用 AES-GCM 加密临时缓存，每块使用唯一 nonce，密钥仅保留在本次服务内存。缓存位于 `%LOCALAPPDATA%/SafetyMask/sessions` 的随机会话目录，文件名不含原图名称或文字。
- 本会话磁盘缓存预算 20 GiB，始终预留至少 5 GiB 磁盘空间；不足时提示释放空间后重试。PNG/JPEG 顺序解码，部分交错 PNG、渐进 JPEG 及 WebP/BMP 解码器还需要额外内存，处理前检查可用内存。图像库禁止自动使用明文磁盘缓存。
- OCR 内容和编辑状态仍在内存。移除图片、清空批次和正常退出时清理相关缓存；下次启动清理异常退出的残留密文，使用系统文件锁区分仍在运行的会话。刷新页面保留当前批次，但浏览器撤销历史和浏览位置重置；退出服务后不恢复图片。
- 上传按块接收并在必要时直接加密，不通过默认 multipart 临时文件；不记录图片正文或 OCR 内容。图片队列加载缩略图，编辑器加载概览及当前可见区域，放大查看不会降低导出分辨率。
- 后端仅监听 127.0.0.1，API 校验本次令牌和来源。前端资源均本地提供，处理进程启用外部网络连接阻断。
- 导出逐段替换像素并生成完整 RGB PNG，只写入 IHDR、IDAT 和 IEND，去掉原始元数据及透明通道。文件名为 sanitized_001.png 等中性编号。生成前及领取下载时校验确认版本，通过短期单次凭证交给浏览器下载，不在前端聚合整张大文件。

自动识别不能保证找出所有隐私。识别异常、零文字和低置信度均要求人工检查；确认代表用户完成检查，不代表算法证明图片安全。请同时检查未遮住的上下文。

## 开发与测试

`GET /api/health` 新增 `memory`：实际 normal/saving 方式、当前物理/提交余量、正在等待的图片 ID 与阶段估计依据。图片新增 `waiting_memory` 状态及 `resource_issue`，区分 memory_preflight、memory_allocation、memory_pressure 和磁盘容量问题。内存等待和重新检查不增加图片 revision；实际识别结果或人工编辑更新时才更新修订，重新处理会撤销本张确认。原重试接口也支持等待释放内存的图片。

性能接口：`GET /api/performance` 与 `PUT /api/performance`（请求 `{"mode":"low_impact"}` 或 `{"mode":"high_performance"}`），同样要求会话令牌。响应区分 requested_mode、active_mode、pending，并返回实际 CPU 预算、计算线程及降级原因；更改模式不修改图片 revision。敏感规则接口保持独立。

依赖由 uv.lock 与 frontend/pnpm-lock.yaml 锁定。模型准备后生成 .models/manifest.json，记录模型文件哈希，并与源码中的 models.lock.json 核对；首次加载也会校验文件完整性。模型、环境、构建产物和合成测试结果不纳入源码。

- 后端：.venv-cpu/Scripts/python.exe -m pytest -q
- 前端：在 frontend 运行 pnpm test 和 pnpm build
- 真实离线验证：.venv-cpu/Scripts/python.exe scripts/verify_offline.py
- 真实进度验证：.venv-cpu/Scripts/python.exe scripts/verify_progress.py（合成长图、接口响应、资源配置及遮盖像素、空白图兼容）
- 低占用性能对照：.venv-cpu/Scripts/python.exe scripts/verify_performance.py（无加速、加速整图、加速分块，串行运行；使用合成图片并阻断外部网络）
- 两档性能对照：.venv-cpu/Scripts/python.exe scripts/verify_modes.py（普通图与 320 行密集长图，实际 Raster 流程，首次及三次预热结果；按用户选择仍暂缓完整速度对照，比较时应记录实际内存处理方式）。
- 真实内存验收：.venv-cpu/Scripts/python.exe scripts/verify_memory.py --mode low_impact --memory auto（普通图及 320 行长图；完整预览、补框、确认、独立 PNG 下载，记录工作集和私有提交量）。可选 high_performance、normal/saving，以及 --cases ordinary dense_320 large_30mp；只使用合成图片和独立会话，不改个人设置。
- 大图完整验收：.venv-cpu/Scripts/python.exe scripts/verify_large_images.py（略高于 3000 万、6000 万、1 亿、3 亿像素；生成浏览器超长图素材与 large-image-report.json）。
- 浏览器验证：先运行真实离线验证生成合成图片，再在 frontend 运行 pnpm exec playwright test。测试使用本机 Edge 和独立的内存规则服务，不修改个人设置。
- 启动开发成果：.venv-cpu/Scripts/python.exe -m safety_mask.launcher

真实离线验证生成文档、带 EXIF 方向的照片、长截图和空白图片，检查预期敏感笔画是否被覆盖、输出元数据是否清理，并保存 test-results/offline-report.json。合成集指标不等同于真实场景准确率。

本地 API 的 `/api/` 路由要求 X-Session-Token。坐标为校正方向后的原图像素，编辑和导出须匹配当前 revision。`POST /api/exports` 创建单张导出任务，`GET /api/exports/{id}` 查询真实生成进度，`POST /api/exports/{id}/ticket` 获取有效期 120 秒的单次下载地址；领取后再校验确认版本。生成任务就绪后 5 分钟内可领取下载，过期可重新生成；已开始传输的文件保留至传输结束。原 `POST /api/export` 保留单张流式 PNG 兼容接口。`GET /api/images/{id}/preview?size=256` 提供缩略图，`/region` 按原图坐标返回最多 2048 × 2048 的区域预览，`POST /api/images/{id}/retry` 重试失败图片。图片状态新增 preview_ready 和 cache，进度新增 preparing（unit=strip）。健康接口返回实际后台资源设置；原图路径和任意导出文件路径均不接受客户端输入。
